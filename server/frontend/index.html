유튜브 따라하기

원본 영상을 1~2초 컷으로 나누고, 컷마다 같은 구도·의상·대사로 AI 영상을 새로 만들며 프롬프트를 배웁니다.

모든 컷에 들어가는 기본 규칙
  • 얼굴은 거의 정면, 눈은 옆 친구 — 입이 잘 보여야 립싱크가 맞아요 (고개를 옆으로 돌리면 입이 가려져 안 움직였어요)
  • 한 컷 = 한 사람 — 화면에 말하는 사람만 있어서 입 모양(립싱크)이 대사에 맞습니다
  • 1~2초씩 — 원본의 컷 전환 지점에서 자르고, 긴 샷은 2초 이하로 다시 나눕니다
