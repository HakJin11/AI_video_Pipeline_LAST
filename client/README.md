# 클라이언트 (client/) — 사용하는 사람 PC

서버 PC(그래픽카드 + 영상 앱)에 **IP로 접속**해서 영상을 만들고 받는 프로그램입니다. 통신은 전부 **UDP**입니다.
설치 없이 `AIVideoClient.exe`만 실행하면 됩니다 (Python 불필요).

> AI 코딩 도구로 실행하려면 이 폴더를 열고 "AGENTS.md 보고 클라이언트 실행해 줘. 서버 IP는 ○○○야"라고 하세요.

## 1. 파일

| 파일 | 설명 |
|---|---|
| `AIVideoClient.exe` | 실행파일 (Windows) |
| `udp_client.py` | 창 프로그램 소스 (tkinter) |
| `web_tunnel.py` | 웹 화면 중계: 브라우저 ↔ UDP ↔ 서버 |
| `proto.py` | UDP 메시지 형식 (서버와 같은 파일) |
| `run_client.bat` | 소스로 실행 (Python 3.11+ 필요) |
| `build.bat` | exe 다시 만들기 (PyInstaller 자동 설치) |

## 2. 실행

1. `AIVideoClient.exe` 실행
2. **서버 IP**(서버 PC의 UDP 서버 창에 표시됨), **포트**(기본 9999), **비밀번호**(서버의 `server_config.json`) 입력 →
   **연결** → "연결됨 · ComfyUI 켜짐 · Ollama 켜짐"이 나오면 성공
3. 둘 중 하나로 사용합니다.

### A. 🌐 웹 화면 열기 — 모든 설정 (추천)
**5. 웹 화면**의 **🌐 웹 화면 열기**를 누르면 이 PC 브라우저에 서버의 웹 화면이 그대로 열립니다
(주소 `http://127.0.0.1:8765`, 통신은 UDP).

- 영상 고르기(10/20/30초), 배경 고르기·그리기, 인물·목소리 바꾸기, 내 사진 올리기
- 컷마다 대사, 시선, ✅ 검증된 동작, 말투, 인원, 샷 크기, 카메라, 프롬프트 직접 쓰기, 예전 프롬프트 다시 쓰기
- 만들기, 진행 상황·남은 시간, 완성 영상과 원본 비교 영상 재생
- **🔧 관리자 화면 열기**: 유튜브 주소로 새 프리셋 만들기

이 창(AIVideoClient)을 닫으면 웹 화면 연결도 끊깁니다.

### B. 간단 모드 (창 안에서)
1. **2. 새로 만들기**: 영상과 길이 고르고 **▶ 만들기 시작** (기본 설정으로 바로 만듦)
2. **3. 내가 만든 영상**: 고르면 진행 상황(완성 컷 수·지금 하는 일·남은 시간)이 5초마다 갱신
3. 다 되면 자동으로 합치고 **⬇ 원본|AI 비교 영상 받기 / ⬇ AI 결과만 받기** → `다운로드\AI영상_받은파일`에 저장 후 재생

입력한 IP·포트·비밀번호는 `%APPDATA%\AIVideoClient\config.json`에 기억됩니다.

## 3. 안 될 때

| 증상 | 확인 |
|---|---|
| "서버가 응답하지 않아요" | 서버 IP·포트, 서버 PC에서 `start_udp_server.bat`이 켜져 있는지, 서버 방화벽 UDP 9999 허용 |
| "비밀번호가 틀렸어요" | 서버 `udp_server\server_config.json`의 password |
| 서버는 켜졌는데 "영상 앱이 꺼져 있어요" | 서버 PC에서 `start_app.bat` |
| 웹 화면이 "서버와 통신하지 못했어요" | AIVideoClient 창이 켜져 있는지, 다시 **연결** 후 **🌐 웹 화면 열기** |
| 회사·학교망에서 안 됨 | UDP를 막는 네트워크일 수 있음 (같은 공유기/사내망 안에서 사용) |

## 4. 소스로 실행 / 다시 빌드
```bat
run_client.bat      :: python udp_client.py (표준 라이브러리만 사용)
build.bat           :: AIVideoClient.exe 다시 만들기
```
